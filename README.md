# CITY Project

Simple full-stack POI (Points of Interest) search app.

- Java backend
- React frontend (Vite)
- (Optional) Python scripts for postprocessing

---

## Requirements

- Java 17+
- Node.js 18+
```bash
java -version
node -v
npm -v
```
- (Optional) Python 3
- (Optional) Maven

```bash
cd WebContent/frontend
npm install
npm install --save-dev concurrently

npm run dev
