# CITY Frontend (Placeholder UI)

This folder contains a placeholder frontend for CITY built with:
- Vite
- TypeScript
- Tailwind CSS

There is **no backend integration yet**. The UI currently uses placeholder/mock data.

## Prerequisites
- Node.js 18+ (Node 20+ recommended)
- npm (comes with Node)

Check your versions:
```bash
node -v
npm -v
````

## Install

From the repository root:

```bash
cd frontend
npm install
```

## Run (Dev Server)

```bash
npm run dev
```

Then open the URL printed in the terminal:

* [http://localhost:5173](http://localhost:5173)
